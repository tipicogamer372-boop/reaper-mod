# Reaper Mod (Fabric 1.21.1)
Stats: 30 HP (15 corazones), 1 de daño, hitbox 0.6 x 1.5, velocidad 0.30.
Compilar: copia esta carpeta sobre el Fabric Example Mod (para tener gradlew) y ejecuta `./gradlew build`.
El .jar queda en build/libs/. Reemplaza reaper.png por tu textura final.
Spawn en juego: /summon reapermod:reaper
